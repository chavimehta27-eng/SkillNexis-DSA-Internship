## Week 1 – DSA Fundamentals & Arrays

### Topics Covered

- Introduction to Data Structures and Algorithms
- Time and Space Complexity (Big O Notation)
- Arrays and Strings
- Linear Search and Binary Search
- Bubble Sort and Selection Sort

### Assignments

1. Linear Search
- Implemented Linear Search using C++.
- Searches for an element in an array.
- Time Complexity: O(n).

2. Binary Search
- Implemented Binary Search on a sorted array.
- Uses the divide-and-conquer approach.
- Time Complexity: O(log n).

3. Bubble Sort
- Implemented Bubble Sort.
- Sorts an array in ascending order.
- Counts the total number of swaps.
- Time Complexity: O(n²).

4. Reverse Array
- Reversed an array without using an extra array.
- Implemented the Two Pointer Technique.
- Time Complexity: O(n).

## Mini Project – Student Marks Analyzer

### Project Description

The Student Marks Analyzer is a C++ program designed to analyze student marks using arrays and sorting algorithms.

### Features

- Accepts marks of N students.
- Sorts marks in descending order.
- Displays the top 3 marks.
- Calculates the average score.
- Displays organized results.

### Concepts Used

- Arrays
- Loops
- Conditional Statements
- Bubble Sort
- Arithmetic Operations

Time Complexity: O(n²)
